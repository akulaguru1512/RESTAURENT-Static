Policies

Transparent by design.

Demo privacy notice

This static application stores selected demonstration state—such as cart, favorites, reservations, orders, theme and profile preferences—in localStorage within the current browser profile. It does not provide secure account storage or cross-device synchronization.

Terms of demonstration

No order, reservation, review, coupon, reward, event enquiry or contact message created here has real-world effect. Pricing and offers are sample data unless integrated with a genuine restaurant service.

Cancellation & refund

Demo orders and reservations can be marked cancelled when eligible, but there is no real transaction to refund. A production implementation would need explicit restaurant cancellation and refund rules.

Accessibility

The interface uses semantic elements, keyboard-operable controls, labelled forms, visible focus states, reduced-motion support and accessible dialog roles. Production testing should still include automated and manual accessibility audits.
